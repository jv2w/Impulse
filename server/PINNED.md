# Pinned behaviour

A `PINNED` marker in a test pins **current** behaviour, not correct behaviour.
A green test run therefore means behaviour has not drifted, not that it is right.

- `BUG` — a defect, deliberately left in place and recorded here.
- `SCOPE` — a feature that is intentionally absent.
- `CONSTRAINT` — a limitation of the test environment.

Before fixing one, read CLAUDE.md section 4.3: a defect fix updates the test and deletes
the marker, while a performance change that breaks one is itself the thing that is wrong.

Totals: 219 BUG, 39 SCOPE, 48 CONSTRAINT.

This file is generated. Regenerate it with:

```
IMPULSE_UPDATE_PINNED=1 go test ./server -run TestPinnedIndexIsCurrent
```
